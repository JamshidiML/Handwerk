## Cycle 2 Outcome

- **Root cause:** npm 11.16.0 had produced a host-incomplete optional-native lock graph on macOS. `@tailwindcss/oxide@4.2.1` named its Linux x64 GNU package, but `package-lock.json` had no resolved record for it. Separately, `actions/upload-artifact@v4` excluded the hidden evidence directory under its default `include-hidden-files: false` behavior.
- **Correction:** `apps/web` now declares exact optional dependency `@tailwindcss/oxide-linux-x64-gnu@4.2.1`, allowing npm to preserve the authentic registry metadata in the shared lockfile. CI uploads only `.artifacts/dependency-inventory.json` and `.artifacts/sbom.cdx.json`, with hidden files enabled, missing files fatal, and 14-day retention.
- **Regression evidence:** a clean Noble/glibc x86_64 container using Node 26.3.0 and npm 11.16.0 installed the Tailwind and Lightning CSS Linux bindings in its only `npm ci`; quality and the cold Vinext build/root suite passed. The emulated local browser run timed out 7 of 35 cases and is not counted as a pass; native hosted Ubuntu completed 35/35.
- **Final evidence identity:** implementation corrections `99e880b59ec2fdc1dedfc8f33bab69804154e463` and `ffcfdd3ac6ab97b67aba09d4d4b411c9fb7d5fef`; this Cycle 2 evidence commit is identified by its immutable SHA in PR #1 and the final handoff because a commit cannot contain its own hash.
- **Outcome:** accepted for the internal synthetic slice only after the Cycle 2 evidence-only branch head also passes all six hosted jobs. This is not production readiness.
