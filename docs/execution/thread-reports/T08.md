## Implementation Notes

- `ProjectPrivacyService` accepts only allowlisted request fields and only emits a schema-versioned JSON attachment with a SHA-256 checksum. The authorised project export can contain user data such as its transcript, but never object keys, signed URLs, raw provider payloads, prompts, secrets, arbitrary audit metadata, or nested source citations/provenance identifiers from the commercial revision.
- The direct deletion path is restricted to explicit demo context with synthetic fixtures. Non-demo deletion records the confirmed request only; execution remains a production blocker.
- The in-memory limiter is intentionally local-process only. Its scope and limits are documented in the threat model, and it is not represented as a production abuse-control solution.
- The package contains no real customer data, credentials, or deployment configuration.
