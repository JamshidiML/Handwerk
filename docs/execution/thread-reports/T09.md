## Security and Privacy Notes

- Metrics accept only fixed, low-cardinality labels. Customer, project, quote, transcript, filename, object key, address, prompt, and signed URL values are rejected or redacted.
- Log attributes are allowlisted; unknown values and exception payloads are emitted as `[REDACTED]`.
- Configuration rejects non-loopback plain HTTP object storage and local placeholders in production configuration.
- `image-size` and `vinext` are the two audited high findings. They are development-only, exact-path exceptions expiring on `2026-08-26`; the T02-owned direct Vinext declaration needs coordinated replacement before then.

## Limitations

- Docker Compose syntax and the health implementation were validated, but the live local container smoke could not complete because the host Docker image pulls did not finish and created no containers. This is recorded as unverified, not a passing readiness result.
- Remote telemetry, alerting/on-call, retention enforcement, managed secrets, backups, hosting, and production privacy/security review are intentionally absent.
- Vinext emits upstream deprecation/config-loader warnings. The serial test command avoids competing writes to `apps/web/dist`, but the upstream toolchain warning remains outside T09 ownership.
